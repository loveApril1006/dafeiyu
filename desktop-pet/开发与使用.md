右键“对话”聊天；“碎碎念”立即说一句；“胡桃语音”可开关朗读；“动作”点播动画。
闲时约五分钟一次碎碎念，近期二十句用于去重；新聊天优先于旧的后台碎碎念。
右键“名字与屏幕陪伴”保存名字后立即影响人设、悬浮提示和菜单；宠物 id、聊天记忆和音色不变。
屏幕陪伴每 4 秒采样鼠标所在显示器，遮掉桌宠自身和设置窗口；明显切换画面时取消过时的生成。默认至少 45 秒点评一次，可设 20～600 秒，静止画面和重复点评不打扰。开启时暂停普通定时碎碎念，手动碎碎念仍可用。
锁屏、休眠、离开电脑两分钟或隐藏桌宠时停止采集；近期聊天优先于自动点评。“现在看一眼”可单次观察，“验证看图能力”仅发送红色合成测试图。模型错误会显示在设置窗口。
屏幕截图通过 DSH 附件服务进入视觉模型，DSH 可能保留附件缓存；不写桌宠聊天记忆，不发 QQ。所选模型与间隔在 .dsh/dsh-pet/screen-companion.json 保存，不含密钥。
使用现有 DSH 模型和胡桃 GPT-SoVITS；先合成语音，播放开始时再显示文字。语音失败时保留文字。
QQ 消息、QQ 工作状态、通知不进入桌宠，聊天记忆使用插件自己的新文件。

明确输入“写日记：内容”“读日记”“逛空间 QQ号”“发说说：正文”“给第1条点赞”“评论第1条：内容”“签名改为：文字”“拍一拍 QQ号”“点歌 歌名”等，转交现有本地生活服务。
空间等写入仅依据用户原始命令，模型生成内容不能执行操作。

## 自己开发功能驱动它

`pet-client.mjs` 会读取本机桥接配置确定 DSH 端口，并使用本机 DSH 认证。不要复制账号密钥或把接口暴露到公网。

```js
import { PetClient } from './pet-client.mjs';
const pet = new PetClient();
await pet.say('提醒你喝口水。');       // 气泡 + 胡桃朗读，不调用聊天模型
await pet.say('纯文字提醒', { voice: false });
await pet.chat('今天想聊点什么？');   // 插件独立聊天与记忆
await pet.animate('动作名称');       // 名称从 API 配置 animations 中选择
await pet.voice(false);              // 关闭朗读
await pet.rename('阿璃');            // 改名，id 不变
await pet.openCompanionSettings();   // 打开原生设置窗口
await pet.screenSettings();         // 读屏幕陪伴设置与状态
await pet.lookAtScreen();           // 单次看屏幕（先配置视觉模型）
await pet.state();                   // 读状态
```

命令行：`node pet-client.mjs say 你好`、`node pet-client.mjs chat 你好`、`node pet-client.mjs voice off`、`node pet-client.mjs show`、`node pet-client.mjs hide`。
示例入口：extensions/example.mjs。不会自动执行；需要时自己运行。
原接口文档：dsh-pet/API.md、dsh-pet/openapi.yaml。SDK 的动作方法会申请并释放占用锁，用户拖拽时仍然优先接管。
自定义播报新增 `voice:true` 参数；`/local-voice` 提供朗读开关；`/speech/<id>.wav` 只提供本次运行生成的有效音频。

## 更新和验证

本地适配在 host/local-speech.ts、host/local-life.ts、host/index.ts 和 runtime/electron-helper/ 下。升级上游前先查看 git diff，合并后保留这些适配，不要直接覆盖。
新增改名在 host/local-name.ts，屏幕状态与模型调用在 host/local-companion.ts，采集和设置 UI 在 runtime/electron-helper/local-companion.js、screen-policy.js、companion-settings.*。截图接入兼容当前 DSH attachments 服务；不要改回裸 image.data，否则新版 DSH 无法读图。
包内已生成 package-lock.json，开发依赖补齐 DSH 类型。构建执行 npm run build，类型检查 npm run typecheck，测试 npm test。
Electron 运行时在用户的 .dsh/electron，配置与新记忆在 .dsh/dsh-pet；本机 local-integrations.json 只保存令牌文件路径，不写令牌值。
本次没有重做约 6 GB 的旧迁移 ZIP；它仍是删除旧桌宠后的 v8，换电脑需要另外部署本插件。

## 娱乐与创作（独立开关）

机器人后台“娱乐与创作”管理音乐、跑团、画图和表情包，四项初始关闭，QQ与桌宠各有入口授权。桌宠直接输入“点歌 歌名”“播放电台 台名”“跑团 开场”“掷骰 d20”“画图 描述”“表情 开心”。这些原始明确命令直达本机机器人后台，不把生成文本递归当命令。聊天朗读会压低音乐音量，结束后恢复；音乐通过既有状态长轮询传递，不另设空轮询。日记和空间等生活功能保持原入口。



语音使用 GPT-SoVITS，保留聊天语音条与桌宠朗读。娱乐与创作提供跑团、画图和表情包。
