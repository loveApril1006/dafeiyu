# 小鸽子桌宠：dsh-pet

当前电脑已部署 PC2005-cloud/dsh-pet 0.3.8，并接入胡桃语音、独立聊天和显式生活命令。
双击桌面“小鸽子桌宠”启动，双击“关闭小鸽子桌宠”停用桌宠；右键可聊天、开关语音、点播动作。关闭桌宠不会关闭 QQ 或共用语音后台。
右键“名字与屏幕陪伴”可以改名、选择视觉模型和开关看屏幕。每 4 秒检查鼠标所在屏幕，默认至少间隔 45 秒点评；画面没变化不重复聊，锁屏、离开两分钟或隐藏桌宠时暂停。聊天优先，点评沿用胡桃语音。
看屏幕通过 DSH 的图片附件接口调用所选模型，图片可能保留在 DSH 附件缓存；不写入桌宠聊天记录，不发送到 QQ。设置中的“验证看图能力”只使用合成红色测试图。
具体开发接口与用法见 [开发与使用.md](开发与使用.md)，源码在 dsh-pet/dsh-pet，扩展示例在 extensions。

保留的后台：GPT-SoVITS 胡桃语音 17866；本地生活服务 17867；QQ Bridge 3100；SnowLuma 5099。插件挂在 DSH 实际端口上，pet-client.mjs 自动查找，QQ 消息不联动桌宠。认证令牌只在本机读取，不复制到 GitHub 或日志。账号写入必须由用户明确下令。

旧桌宠的程序、动画、屏幕陪看、碎碎念、麦克风代码和旧日记记录均不用于新插件。
新版屏幕陪伴为独立实现，麦克风仍未接入；旧迁移 ZIP v8 尚未包含本插件，仅复制本目录说明也不代表插件已安装。
