大肥鱼连接QQ指南

首次配置：
1. 自行从所选框架的官方渠道安装到大肥鱼目录的独立子文件夹，阅读许可。也可点击“复制给DeepSeek的安装说明”，自行粘贴到DeepSeek并指定框架，让其协助安装。此程序不自动下载或部署框架。
2. 在框架内开启 OneBot v11 HTTP API、正向通用WebSocket服务端、事件上报（建议启用心跳）。此入口不接反向WS。
3. 打开“大肥鱼 → 启动 → 连接QQ / 桥接设置”。填写实际地址与Token，例如 HTTP http://127.0.0.1:3000、WS ws://127.0.0.1:3001；端口以框架实际设置为准。HTTP和WS认证不同可分别填写。
4. 勾选“自动启动安装目录中的QQ框架”。已知框架入口可自动检测；其他框架首次通过“选择文件”指定正式启动入口，再点“保存并连接QQ”。它会测试两个接口是否属于同一个QQ账号，再应用配置并连接自己的QQ桥接。外部框架由用户管理。
5. 点击“设置QQ回复白名单”，填写允许回复的私聊QQ、群号；管理员在访问与安全中设置。
6. 回启动页点“一键启动”，启动模型、生活服务、桌宠和语音。使用已在白名单内的账号发送一条消息，检查实际收发。

日常使用：打开大肥鱼点一键启动；已检测/指定的框架会随启动。首次或掉线时，需在框架内自行完成QQ登录。关闭随启动开关后，框架需自行运行。
缺少框架：连接QQ页面会提示安装，并可复制给DeepSeek的安装说明；装完后点“重新读取 / 检测框架”。
仅检测到文件夹、有进程、QQ已登录、OneBot接口可用是不同状态；接口成功后才代表桥接可连接。外部框架保留自身配置和许可，大肥鱼退出时不强制关闭它。
正常链路：QQ账号 ↔ 外部框架的OneBot接口 ↔ 大肥鱼QQ桥接 ↔ 聊天模型。

排查：
- HTTP/WS未连接：检查端口、Token、正向WS配置、QQ登录和事件上报。管理网页可访问不代表OneBot已启用。
- QQ桥接已连接、模型未连接：点一键启动并在模型与账号中完成配置。
- 连接正常但不回复：核对发送者/群聊是否在白名单、是否暂停，以及模型额度。
- 语音/表情/空间等扩展是否可用，取决于所选框架实际接口能力。
