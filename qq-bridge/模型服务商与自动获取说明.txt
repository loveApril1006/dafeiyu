模型服务商与自动获取（2026-10-26）

使用步骤
1. 正常重启QQ Bridge，加载新的模型设置接口。只刷新网页不会重新加载后台代码。
2. 打开“模型与账号”，在“模型服务商 / 快速填写”中选择阿里云百炼、Google Gemini、OpenAI / GPT、DeepSeek、硅基流动或Anthropic / Claude。
3. 填入该平台的API Key。百炼需使用与密钥对应的地区或工作空间地址；兼容中转服务可选“自定义兼容 API / 中转服务”，填写自己的API根地址与协议。
4. 点击“获取模型列表”。页面会获取该服务实际返回的模型ID，支持分页读取、名称搜索、模型分组和图片能力筛选。
5. 勾选需要的模型，或点击“全选当前筛选的聊天模型”，再点击“添加勾选的模型”。手动填写的原有模型会保留。
6. 检查下方模型ID和图片能力，再点击“保存服务与模型”。获取列表和添加到草稿不会自动切换QQ模型。
7. QQ模型可在页面上方选择并点击“使用此模型”；抖音模型在抖音自己的模型设置中选择，使用图片能力前仍需视觉测试。

编辑已有服务
在“已有API服务”选择服务并点击“编辑所选服务”，然后获取模型列表。密钥框可留空，后台只会为同一服务地址与协议使用本机已保存的密钥。修改地址或协议后重新填写对应密钥。已保存的密钥不会返回浏览器。
在“模型服务商 / 快速填写”选择硅基流动等平台时，如果已经有对应的可用服务，会自动载入已有配置。要新增另一个账号，可再点“新增服务”并使用新的服务标识。
密钥框有新值时，获取列表优先使用新输入的密钥，不受旧密钥影响；获取列表不会保存新密钥，点击“保存服务与模型”后才替换。只粘贴密钥本身，不要附带中文说明或 Bearer 前缀。
已为旧后台的笼统网络失败提示增加一次页面重试。新版后台会重试临时连接异常，并分别提示地址解析、连接超时、证书验证、连接拒绝或跳转问题；这些后台改动在下次正常启动桥接时加载，证书校验及密钥跳转保护保持启用。

协议
OpenAI / GPT 默认使用 Responses；Gemini使用官方OpenAI兼容地址；百炼、DeepSeek、硅基流动默认使用 Chat Completions；Claude使用原生 Anthropic Messages。其他服务可选择匹配的兼容协议。

列表范围与手动补充
返回的是该服务与密钥可见的目录，不是全市场所有厂商的统一目录。平台未开放列表接口时，页面会明确提示，可继续手动填写模型ID。
接口未提供图片能力时，已核实的硅基流动 DeepSeek-OCR 和部分 Qwen-VL 型号按官方文档补充，并标注来源；其余显示“图片能力未知”，可参考对应平台说明手动勾选并测试。接口明确提供的能力优先于文档补充，其他地址和未知型号不会仅凭名称自动启用。
DeepSeek-OCR 主要用于文字识别；抖音画面、颜色和界面理解建议选择 Qwen-VL 等通用视觉模型。图片输入配置与实际视觉测试结果分开，未通过测试不会启用自动操作。
嵌入、重排序、语音、生图等已识别的专用模型会展示，但不允许添加为QQ聊天模型。
最多获取5000个目录条目，每个服务最多保存1000个聊天模型；达到上限会明确提示，不会悄悄丢弃勾选项。

验证范围

硅基流动列表恢复验证：控制台接口与真实网页都成功返回98个模型。已载入并继续使用原有服务配置；获取操作未保存新密钥、改写模型列表或切换当前模型。
2026-10-26 图片输入与返回兼容修复：当前硅基流动服务中的 DeepSeek-OCR 和 6 个已导入 Qwen3-VL 模型已配置图片输入，原有92个模型和密钥保留。抖音当前选择 Qwen/Qwen3-VL-8B-Instruct，真实合成图测试已通过，页面显示“视觉连接：测试通过”。

临时模型调用会识别 turn/end 中的服务商错误，将余额、密钥、限流等原因转换为明确提示；不会回显可能包含密钥或请求内容的原始错误正文。如果后续出现 HTTP 402，请检查对应服务的余额或额度。
