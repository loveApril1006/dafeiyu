# 识海记忆

## 四层记忆与插件协作

识海保留四层，不是因容量接续修复而减少层次：

| 层次 | 内部标识 | 当前行为 |
|---|---|---|
| 永久核心 | `core` | 当前人格、锁定的记忆等不随时间自动衰减；管理员操作和人格配置仍可改变记录 |
| 时序动态 | `active` | 普通近期记忆，活跃度通常不低于 0.4，按类型、时间和重要性变化 |
| 渐淡记忆 | `warm` | 活跃度低于 0.4、但不低于 0.08，逐步减少摘要占用，保留原文来源 |
| 久远归档 | `archive` | 活跃度低于 0.08、已到期或手动归档的普通记忆；主记录和原文保留，可追忆召回或恢复 |

这是同一识海主库中的记忆状态，不要求使用四个独立数据库。具体判定优先级见 `ocean-memory.js` 的 `view()`；衰减及维护见 `memoryActivation()` 和 `maintain()`。归档不等于删除，管理端撤回另有墓碑与召回排除规则。

`memory-context.js` 继续统一协调 Mnemon/Context、人格情感和平台经历。Mnemon 接收当前会话容量内的精简投影，不替代四层主库；Context 提供容量统计与预算；新加的会话交接只轮换短期模型会话。插件是否已连接仍以“系统协作”的实时状态为准，存在适配代码不等于当前引擎在线。

星图总览此前使用“核心／活跃／渐淡／归档”缩写，容易造成层次减少的观感。现统一显示“永久核心／时序动态／渐淡记忆／久远归档”，逐条记忆同时标示所属层次；层次选择器和详情原有完整名称保留。这里只改显示，不重分层、不修改记忆数据。

## 同图展开、记忆线与聊天轨道（2026-10-30）

圆环动效包括三道错向光带、扫描光、移动刻度与环上信标；核心和神经团有轻微呼吸，已有关系线与原文来源线上有流动光点。圆环使用独立的可暂停动画时钟，悬停聊天仅暂停文字轨道。关闭动效、系统减少动态效果、页面隐藏或离开星图时停止持续绘制，恢复时不跳过暂停期间的相位。这些常规光效是本地绘制，不新增记忆、活动日志、模型调用或 QQ 消息；真实归档/撤回陨星仍以生命周期回执为准。

默认入口改为同图展开：左侧逐条显示实际记忆，中央直接绘制独立星点，右侧显示真实活动日志。记录通过游标自动分批加载到同一视图，不再默认逐层进入分类，也不只取每类 3 条样本。左栏采用虚拟列表，滚动浏览全部已展开记录；读取单条详情在原图下方打开，图中内容保持不变。「关联浏览」及关系脑图保留原有导航，供需要详细追溯时使用。

新增 `public/ocean-flow.js` 是既有本地 Canvas 星图的独立扩展。每条记忆有位置引线和分类虚线，已有关系与原文来源使用实线，三者不混为新的事实关系。装饰光丝不计入数据数量；高密度时缓存实线的绘制细节最多使用 24,000 条关系和 24,000 条来源线，主记录与来源索引仍保留在当前展开数据中，不限制主库存储。真实节点不再受旧分类页面 160 节点绘制批次的限制。

聊天轨道自动轮转当前人格、当前会话有来源的原文片段，桌面每轮最多展示 10 个文字标签，窄屏最多 6 个，后续批次继续轮换；不是把整段历史同时挤在画面上。文字始终正向，悬停或键盘聚焦时暂停，并在右侧展开当前片段；关闭动效或系统减少动态效果时保持静止。切换范围立即清掉旧片段，空会话不显示上一个会话的原文。聊天统计指已展开的可用来源数量，不冒充全部原始归档数量。

`GET /api/memory-context/field` 复用管理端鉴权与 agent 禁用规则。记忆、聊天、已存关系和来源关联分别按游标分页，每批上限分别为 120、80、400、400；前端自动续读，在页面隐藏或离开星图面板时暂停后续请求。聊天要求当前人格的实际 `ocean_refs`，被撤回或编辑而失效的证据不再进入轨道；不会把同一 QQ 会话里其他人格的原文直接混入。角色或导航已变化的旧请求被丢弃。读取不调用模型、不写记忆内容或强化数值。

右侧日志取实际功能经历、反思、自言自语、复习、内部任务状态和归档撤回回执，不模拟派单、交接、活跃率、token 或费用。刷新状态时核对修订，新增或变更记录重新接入同一视图。新增消息索引用于按会话和编号读取；只增量创建索引，保留原始聊天、人格、情感、Mnemon/Context 和用户媒体。

新增验证：`node scripts/test-ocean-field.mjs`、`node scripts/test-ocean-flow-ui.mjs`。覆盖跨批次完整展开、205 条人格隔离聊天、真实来源线、撤回排除、虚拟列表、聊天旋转与悬停暂停、原图详情/归档/删除、鉴权、空会话清理和手机布局。测试只用隔离合成数据，不向 QQ 发送消息或发起真实模型请求。

## 关联浏览中的记忆岛与叙述边框

「关联浏览」的分类总览继续支持记忆岛：每区显示说明与最多 3 条真实片段，完整历史通过原有列表分页。它是可选的分类视图，不再作为默认展开方式。记录较多时显示未展开数量；桌面根据卡片实际高度排布，手机顺序阅读。

视觉采用海绿、灰紫、暖金与开放的叙述轨道。边框文字来自分区说明与真实记忆标题，替换战术侧栏、热力格、能量格和多层仪表环。记忆岛的说明是产品导读，不冒充新生成的回忆或模型思考。神经光丝由本地程序生成，含分支路径、空间邻域短线、核心纤维与流动光点；缓存随视角更新，不计入真实关系或额外记忆。关系脑图、回忆路径、来源、详情、导航、动效关闭和离屏暂停继续使用原有行为。有限绘制预算不限制主库记忆数量。

`GET /api/memory-context/panorama` 复用管理端鉴权，拒绝 agent token，按当前人格和 QQ 会话读取分类总数与最新片段；每类最多 3 条，摘要最多 150 字符。读取不修改版本、强化时间、情感或来源。前端校验会话、导航代次与人格，丢弃旧请求；切换范围立即清掉旧片段。网页通过文本节点展示原文，不执行其中的 HTML 或指令。此接口不请求模型，也不启动额外插件。

普通记忆渐淡到归档、手动归档、管理端撤回时，主库在同一事务内写入 `ocean_lifecycle` 回执。每条回执对应一颗陨星，归档回执为青色，撤回回执为暖色。回执仅含递增编号、会话、人格、节点编号、类型、原因与时间，不复制记忆正文或标题。归档仍可恢复，撤回仍遵守墓碑与召回排除规则；动画不会修改记忆强度、情感或人格。

`GET /api/memory-context/lifecycle` 复用管理端鉴权与 agent 禁止访问规则，按会话和当前人格隔离。首次打开或切换范围建立当前游标，不回放旧事件；后续以游标每批最多读取 64 条，按序逐条播放，刷新与翻页不制造陨星。当前星图开启时沿用 15 秒状态刷新读取回执；后台渐淡需先经过原有维护轮转。离屏暂停，关闭动效或系统减少动态效果时只保留文字回执，不播放坠落动画。页面重新打开时不补播关闭期间的事件。

本次新增星轨和陨星实现基于 QQ Bridge 原有 Canvas 星图独立编写，没有复制、引入或分发下载目录中的参考 `index.html`、其中的神经星环代码、字体或其他素材。该参考文件头部声明 `PolyForm-Noncommercial-1.0.0`，改名或修改不解除其非商业限制。新增代码随项目原许可证；这不是对整个产品及其第三方组件的商用许可保证，仍须按项目 LICENSE 和各依赖原许可处理。

新增隔离验证：`node scripts/test-ocean-lifecycle.mjs`、`node scripts/test-ocean-lifecycle-ui.mjs`。后者沿用现有 UI 测试的 Playwright 和 Chrome 环境，可通过 `PLAYWRIGHT_MODULE` 指定模块、`MEMORY_UI_SCREENSHOT` 输出合成数据截图。测试覆盖事务回滚、归档恢复、撤回、去重、分页、范围隔离、受保护核心、接口鉴权、手机布局、动效关闭与减少动态效果，不操作真实用户数据库或调用模型。

「系统协作 → Mnemon 当前会话」通过 dsh-mnemon 自己的 `dshMnemon/read`、`runtime-memory` 接口核对所选 QQ 会话的精简记忆，显示版本、条数、来自识海的投影和原有 Mnemon 条目，并可回到星图中的原记录。接口只读，不调用模型；返回的 USER.md / MEMORY.md 路径必须与该会话工作区一致，避免误读插件默认根工作区或共享画像。当前根工作区为空并不代表其他 QQ 工作区没有记忆。

主库保留完整记录，Mnemon 只接收容量内的精简资料。未投影数量与手动编辑冲突分别展示，未同步内容继续由识海按预算提供。会话创建、官方读取校验与文件同步共用同一个工作区解析函数，包括自定义 `sessionCwd`。不把多个 QQ 会话合并为一个全局记忆区。

识海是 QQ Bridge 的内置模块，入口仍为 `#memory-context`。不需要安装新插件。

## 数据与来源

- `state/conversation-memory.sqlite` 的原 `messages` 表继续是唯一聊天归档。新增 `ocean_*` 表保存人物、事件、事实、来源关联、版本、索引和内部活动记录。
- 人格引用当前启用的角色卡。修改名字和关系以角色卡为准，不由记忆内容推翻。
- QQ 旧轻量记忆、原情感记忆、Mnemon 手工条目按会话导入，保留来源。旧文件保留；迁移按游标执行，可重入。
- 结构化记忆没有总条数上限。近期数组是原有工具的兼容缓存，旧条目退出缓存不会删除识海主记录。
- 人物以 QQ 身份、会话范围和角色范围隔离；昵称不用于合并身份。不能识别 QQ 的旧印象保留为来源记录。

## 五层处理

核心记忆可以锁定。动态记忆按时间归档；普通事件用半小时会话片段组织，关联原始消息，不为每句话生成一个星点。SQLite 主记录、人物索引、时间索引及中文关键词全文索引共同支持检索。摘要随活跃度逐步缩短，原文仍可按来源分页展开。

遗忘活跃度采用可解释的半衰期近似，不宣称是对人脑的精确模拟。不同类型使用不同半衰期。锁定与人格不自动淡忘。查看、后台扫描、模型复习不强化可信度或关系数值。真实新陈述可更新有效时间。归档可以恢复。

管理端删除是带墓碑的记忆撤回：不再参与索引、投影和召回，旧来源不会在重启或同步时重新创建。相关原始聊天保留，关联证据退出自动召回。手工编辑保留版本；上游变化产生冲突提示而不覆盖编辑。并发编辑按版本拒绝过期提交。

## 情感和上下文

### 容量到达前自动交接（2026-10-30）

识海在向 QQ 模型会话提交新问题前检查工作上下文。高级设置 `contextMemory.maxContextTokens` 默认 400000，`handoverRatio` 默认 0.85；有效工作预算取引擎标称窗口与本地预算的较小值，已知当前用量加输出预留、当前输入及附加材料的估算接近阈值时，先交接再投递。40 万是可调的本地保护预算，不代表 DeepSeek 或其他服务的硬上限。设为 0 表示只使用引擎报告的窗口；比例范围 0.5～0.95。旧安装未配置这些字段时使用上述默认值，覆盖安装保留用户原配置。

容量优先来自 Context/压力统计；另外接收当前会话的单次模型请求 usage，包含输入、缓存读取、缓存写入及输出，不使用费用账本的累计 token 数。只带输出的片段不覆盖已有输入采样。没有新请求的空闲会话仍保留上次单次请求用量；普通运行时压力快照超过 90 秒则失效。重连时可从快照中的单次请求事件恢复采样，不把累计账单当作当前上下文。

交接在撤销旧会话映射之前保存到原有私有 `state/context-health.json`。材料来自当前人格/会话仍有效的原文引用、已记录的未完成事项、精简主记忆及与当前话题相关的召回，采用不超过 7000 字符、保持结构完整的 JSON 摘录，不额外调用总结模型。原始聊天和主记忆保留在数据库中，不把整段旧上下文搬进新请求。没有可用归档材料时明确记录 `hasArchivedContext=false`，不虚构接续内容。人格正文仍按当前卡注入，Mnemon 保持原固定会话工作区。

新会话在首次接受请求前重新核对资料与人格版本，撤回和编辑失效的原文不会被旧笔记带回。当前问题与排队顺序保留；正在处理的模型回合及最终回复发送先完成。新会话创建失败则保留当前请求和已落盘交接，等待连接恢复；首次请求接受后不重复附加笔记。正常的提前交接不消耗失败恢复额度；错误后的恢复仍按每会话每小时最多两次保护，达到失败上限后暂缓交接与请求，避免循环失败。

收到明确的上下文超限错误仍走交接。对于笼统 HTTP 400，只有当前会话的容量证据已达到上述阈值时才进入同一有界恢复路径；没有容量证据的参数错误不触发换会话。不据此宣称知道服务商没有传下来的具体错误体。

这条自动交接路径不依赖手动 `#重置`。它保持已归档记录可检索，并在模型有限窗口中提供必要接续材料；不保证摘要等同于完整旧上下文或包含未归档的模型工具中间状态。单次巨大输入、一个模型回合内部的工具输出增长、统计缺失以及服务商其他请求限制仍需分别处理。当前改动不修改引擎的压缩实现，也不能证明另一台电脑已更新生效。

验证入口 `scripts/test-ocean-handover.mjs`，覆盖缓存读取计数、提前交接、未读/排队保留、同工作区、未知 400 拒绝误判、容量高时恢复、撤回/人格重查、重连采样、旧回复不被取消和创建失败后的请求恢复。全部使用隔离数据库及假服务。

现有 `emotional-companion.sqlite` 继续保存和计算心情、好感、信任、作息、免打扰及主动联系次数。QQ 偏好写入识海，聊天只注入情感状态，避免再次附加同一份偏好或日记。永久消息去重表防止超过旧近期窗口的重放重复增加关系数值。桌宠的现有本地工作状态保持原接口。

「情感状态」里的拟人设置控制情绪表达、互动性格学习、适度脏话和表达强度。新对话可影响开心、生气、委屈、关切、兴奋等状态，情绪变化与关系加分冷却分开；引用、被别人辱骂、道歉和停止互怼分别处理。关闭表达开关后，本地心情不再影响聊天语气。实际措辞由当前聊天模型结合人格卡和对话生成，不使用固定骂人模板。

互动性格仍保存在原情感档案中，按角色、会话和成员隔离，记录亲近、玩笑、直率、谨慎四种缓慢变化的倾向。每成员每天最多学习 12 次、至少相隔一分钟，单次只作少量调整；长期闲置缓慢回到基调。新设置不会回放旧聊天来伪造成长。查看、召回、自言自语和反思不增加样本。重置互动性格只清除该成员的学习倾向，保留人格卡、关系、情绪和记忆。计算不调用模型，表达提示仍受原有字符预算限制。

## 人物关系与自生副人格

「人物关系」按当前人格保存 QQ 号、关系类型、称呼和备注，支持常见亲属、恋人、老婆、老公及自定义称呼。管理员设置后在该人格的群聊和私聊中通用，聊天冒认、昵称和低好感不会改变它。当前后台关系优先于旧人格正文中对同一人的称呼，未配置的仍回落人格卡；关系不赋予工具或管理员权限。接口仅控制台可写，编辑与删除校验版本及人格，避免旧页面覆盖新设置。

关系在当前会话中对应到实际参与者后进入永久核心，并形成金色亲戚线。总览最多直接展开六个亲属节点，其余仍可从关系分类与分页后台列表查看。QQ 关系表与感情数值独立，设置为恋人不会自动提高好感或亲密数值。

每个会话的永久核心引用当前人格的同一份「自生副人格」倾向：聚合该人格各会话的精简性格指标，不复制或注入其他私聊原文。六次有效的性格学习样本后形成侧面，之前显示“正在形成”。生成是本地、可追溯的自动沉淀，不另开模型任务，不会自行改名或创建新亲属。只在新的有效学习发生后演化，查看不强化；已形成的永久核心不因单人成长重置而被抹除。精简指标有独立索引，避免每轮反复解析所有人物档案中的聊天内容。

副人格线为紫色，并可关联当前会话的实际互动和反思线索。核心内容不提供手工编辑、删除、归档或解锁；接口也拒绝这些操作。它只作相处方式参考，不能替代主人格、事实、后台关系或权限。关闭拟人表达时停止注入这一参考，数据仍保留。只读指应用内管理规则，本机数据库和备份仍由用户控制。

## 上下文与故障处理

人格和本轮任务先保留，情绪、工作记录、视频状态和记忆召回使用一份最多 6,000 字符的附加预算；有当前容量统计时，再扣除输出预留和已有提示长度来收紧。情绪与工作记录共同遵守原情感模块预算，JSON记录和召回标题都计入容量。极小预算使用简短表达边界或省略可选材料，原数据库内容不截断。字符估算用于提前减压，最终仍由引擎压缩与上下文超限恢复处理服务商的实际 token 限制。

`contextMemory.enabled` 在配置加载时生效。可选记忆准备默认最多等待 4 秒，异常或超时不阻断当前 QQ 消息；高级配置 `contextMemory.prepareTimeoutMs` 收敛到 50～10,000 毫秒。同一会话的投影同步统一排队。自动活动请求默认 90 秒截止，取消、超时和关机后都不接收迟到的模型结果；超时不自动重试付费请求，取消也不能撤回服务商已经发生的用量。桥接退出时对未响应的可选后台工作作有界等待，迟到的迁移不得重新启动后台调度。

边界与恢复使用可用的原始证据：引用中的“恢复联系”不改变成员设置，消息重放不增加工作统计，关切状态按最后真实互动时间缓和。编辑或撤回记忆后，旧来源仍供审计，但不进入下一次恢复交接；已有旧交接缓存同时失效。记录损坏、网络失败等错误不会通过删除用户数据库来“修复”。

## 自言自语、反思、复习

一个内部调度器合并三种活动，每次只处理新增消息和少量轮转复习材料。默认每会话最短间隔 30 分钟、至少 3 条新消息，每日 6 次模型请求和 18,000 token 本地预算。预算设置为 0 可取消该项上限，这与总记忆量无关。

## 星图

星团、可点击的星点与详情来自同一份真实记忆。背景星尘只用于视觉效果。按类别、层次、人物和事件逐步展开，列表、来源及高连接度关系使用游标翻页；单批绘制预算不限制总存储量。

三维视图按总览、分类、具体记忆展开，中心节点和分类连线帮助识别层次。虚线只表示分类归属，实线来自已记录的关系，不凭视觉生成虚假人物联系。面包屑逐级返回，悬停提示与分类条目提供操作入口；关联较多时逐批展开。详情中的返回按钮、星图工具栏的上一级按钮及面包屑返回后，自动将当前星图滚动到可见位置，并保留星海或关系脑图模式；内嵌控制台与独立页面共用这一行为。

星图使用本地 Canvas 绘制三维坐标、透视、深度明暗和空间曲线，保持整幅画面居中。当前焦点显示为立体网格核，分类周围的星雾仅是装饰，真实节点数和连线数单独显示。点击分类或记忆后，详情面板在星图下方按正常文档流展开，不使用绝对定位，也不压缩星图绘图空间。桌面面板独立滚动，手机随页面展开；可用关闭按钮、记忆详情按钮或 Esc 收起，收起不会改变导航。正视复位只恢复相机，保留当前人物或事件；总览按钮返回分类入口。

支持旋转、缩放、光点呼吸、连线光点和星海/关系脑图过渡。背景星尘缓存后复用，氛围动效可关闭；系统偏好减少动态效果时默认关闭。页面隐藏或离开视口暂停绘制，弱设备减少装饰粒子。前端不加载第三方脚本，不把全部历史发送给模型。

关系脑图采用左右半球、中央裂隙、弯曲皮层线条和脑干轮廓，人物与事件节点沿脑体分布，可继续点击读取同一份记忆。脑形表面网格和沿表面移动的光点属于装饰层，不计入真实关系数量。脑体几何与背景缓存在视角变化时更新，持续动效只绘制少量光点；星海坐标与绘制效果独立保留。

真实聊天、已接入功能回执、家园互动及重新布置能提供变化信号；状态还随当前活动和经过的时间连续变化。睡眠/休息恢复精力，聊天和工作消耗，聊天满足表达欲，翻书/观看满足好奇，整理/复习恢复秩序，经历和放松酝酿创作欲、创作消耗一部分。其余状态缓慢趋向基线。写入信号按人格+来源类别+事件摘要指纹去重，仅保存索引，不复制聊天正文；每小时直接事件影响有上限，持续活动仍按时间计算。刷新或多次查看不强化、不消耗状态，不新增叙事记忆。

状态引擎复用记忆协调器现有60秒维护节拍，不新增模型循环。离线后的未观测时间按基础作息进行虚拟恢复，单次运算最多逐小时处理最近24小时，其余使用有界衰减估计；不补造“已经看书/完成任务”的事实。重启读取持久化检查点，不因打开页面重新抽取随机数；长离线和时钟回退保持数值有界。

自由活动可根据低精力选择睡眠、低秩序选择整理、高好奇选择翻书、高创作欲选择酝酿点子；想说话只提供状态描述，仍由原有主动联系设置和权限决定实际发送。真实聊天/任务优先，不因精力不足擅自停任务或关闭功能。状态只在管理员私聊相关鱼窝问题中随现有上下文预算提供简短提示，不把家园细节共享给群聊。

安装现有桌宠没有独立的完整躺睡素材，睡觉由已有透明形象的安静帧、跟随床方向的躺睡姿态、轻微呼吸与Zzz构成。关闭动效会冻结呼吸、Zzz和视频；离屏暂停渲染。可主动安排一小时睡眠，夜间23:00–07:00和低精力也会在自由活动下选择睡眠；状态卡里可轻轻叫醒。睡眠安排仍有虚拟标记，不声称现实身体睡眠。

界面顶部五个状态卡显示数值和简短含义，点击可查看变化逻辑、最近一次信号和关联的放松动作。新增整理与酝酿动作都是虚拟生活安排，不触发真实创作、发送或浏览任务。


## 角色与家具碰撞修正（2026-10-30）

共享几何模块 fish-home-space.js 根据家具实际占地、椅子、旋转和房间边界选择安全站位；查看/移动不改动用户家具坐标。角色以固定半径避开桌面、椅子、床、书柜、花盆等，地毯可通行。前后端复用同一几何；A*搜索和路径简化检查整段间隙，优先绕行，站点不可达则选附近可达空位，不穿过实体或斜切墙角。布局改变/取消布置时重新规划，家具拖到角色附近时角色避让。

清醒形象改成保持竖直、仅随镜头水平朝向的透明平面；睡眠形象单独贴合床面的水平面，透明像素不写深度，实体像素按真实深度遮挡。先到床边的可达点，再切换到床面，醒来回到床边空位，不把竖直人物塞入床体。原桌宠仍是透明动画素材，不伪称新建三维骨骼。自由走动短时保留，不因每3秒刷新重设路径；真实功能仍优先。
