# 肥鱼生活总部

## 房间工作台与进度（2026-10-30）

新版按照生活状态卡、八个区域入口、三维沙盘与独立详情栏、生活记录排列。详情栏使用正常网格布局，有自己的内容滚动区，不覆盖沙盘；每个房间分为概览、记录、互动与设置三个页签。

| 房间 | 直接可用的操作与信息 |
|---|---|
| 中央书房 | 当前真实活动、自动生活开关、个人状态、家园日记、回原房间布置 |
| 会客聊天厅 | QQ连接、聊天处理状态、会话审批、当前人格、回复设置、白名单 |
| 识海图书馆 | 核心/活跃/渐远/归档分布、可用记录、进入星图、翻书/回忆/整理活动 |
| 影音放映厅 | B站/抖音任务状态与已有经历、B站观看轮数进度、原有影音及聊天联动入口 |
| 灵感创作坊 | 已运行创作活动、已有创作经历、画图/音乐/剧情入口、本地酝酿灵感与日记 |
| 生活事务室 | 管理员私聊待办约定、任务运行状态、原Harness入口和识海备忘入口 |
| 直播互动间 | 实际已启动的直播状态、已有直播经历、直播工作台与人格入口 |
| 空间编辑室 | 实际空间任务状态与已有记录、原草稿/发布入口、家园心事与灵感活动 |
| 安心休息室 | 当前精力、手动睡眠/休息安排的时间进度、睡觉/叫醒/休息、日记与原房间 |
| 门厅与茶水区 | 玩耍、自由走动、摸摸、零食与发呆活动 |

任务进度只使用可核对的数据：B站按 finishedRounds/plannedRounds 显示；没有完成量的工作显示不定进度条和实际阶段，不把工具预算或经过时间推算成完成百分比。五种生活状态是0–100状态值；记忆色条是分层占比；休息倒计时是本次手动安排的有效期，均分别标注。平台功能仍使用原有工作台、权限和发布流程，不在总部再复制一套。

`src/fish-hq-runtime.js` 限量读取本机任务记录和已初始化服务的内存状态；不调用远程接口，不初始化新平台服务。任务面板不展示其他聊天的原文、任务标题、会话ID或凭据。房间记录只使用原有管理员私聊记忆，保留按来源过滤和撤回规则。

日记复用原有角色修订检查、幂等编号、操作冷却与管理员私聊归档。自动生活开关复用原有设置版本校验，不重置家具。场景支持平滑聚焦、跟随肥鱼、缩放、房间悬停高亮、活动区域光晕、导航路线和互动反馈；路线缓冲区复用，光照按时间缓存，静态模式和系统减少动态效果会停用持续动效。

发布时额外包含 `src/fish-hq-runtime.js`，同时更新总部前后端、协调器、桥接、原鱼窝记忆来源字段和控制台功能跳转白名单。用户数据与安装默认保持原有保留规则。

生活总部是现有肥鱼、识海和功能状态的一张三维视图。入口为控制台侧栏「肥鱼生活总部」，也支持 `/#hq` 和独立页面 `/fish-home/hq/`。使用原有控制台凭据。

## 场景与交互

原创肥鱼住在中央书房，四周是会客聊天厅、识海图书馆、影音放映厅、灵感创作坊、生活事务室、直播互动间、空间编辑室、安心休息室，南侧是门厅和茶水区。建筑、家具及角色由几何体生成，没有模拟员工、虚构项目或演示完成率。

- 点击房间或底部区域栏可聚焦，房间下方给出状态和原有功能入口。
- 拖动旋转、滚轮缩放、双击回全景；全屏覆盖整个总部，包括区域栏和交互弹窗。
- V 切换全景/巡游/俯视，N 切换实时/白昼/黄昏/夜晚/循环，T 切换深浅主题，C 安排生活，H 查看肥鱼；1–8 进入区域、0/Esc 回全景，左右键切换区域。弹窗输入时不抢快捷键。
- 实时光线按北京时间变化；遵从系统减少动态效果，支持手动静态显示。离屏或页面隐藏时暂停绘制与定期读取。
- 肥鱼沿独立导航图与最短路径移动，从门口进出，不穿越房间墙面。休眠时使用床上的睡姿、呼吸和 Zzz；醒来回到床边安全点。自由游动使用同一走廊图。
- 「我的房间」保留原有家具布置、日记和生活设置；从总部进入使用 `character=original` 原创肥鱼模式，可返回总部。

## 与真实系统的关联

`src/fish-headquarters.js` 通过 `src/memory-context.js` 读取同一个 `home`、`ocean`、`activities` 和原始消息计数。没有再创建记忆数据库或情感引擎。

| 数据 | 来源及含义 |
|---|---|
| 名字、心情 | 当前人格与已有情感状态；查看不改变关系数值 |
| 精力、好奇、想说话、秩序、创造 | 原有 `fish-home-vitals` 的持久状态 |
| 当前区域 | 原有真实运行活动或本地自由活动映射 |
| 识海主记录、功能经历 | 当前人格数据库记录总数，非神经元数量或完成率 |
| 待办与约定 | 管理员私聊下尚待处理的备忘/约定，排除私人日记及已撤回节点 |
| 聊天归档 | 本机原消息总量，最多缓存 15 秒；不读取其他聊天原文展示 |
| 生活痕迹 | 已有管理员私聊的记忆摘要与家园日志，保留来源跳转 |

QQ 聊天、B站/抖音观看、创作、空间、直播和任务状态继续走既有运行观察器。真实运行任务优先于手动放松；点击房间只改变镜头，不会启动对应服务。生活安排继续调用原有 `/api/fish-home/action`，保留角色修订检查、幂等请求、操作冷却、来源开关和原始会话隔离。

只有明确安排活动或写日记才沿用原有记录流程；观看、旋转、切换光线/主题和读取计数不新增记忆、好感或模型请求。管理员私聊按问题需要可引用当前虚拟总部位置，沿用原上下文预算；其他群/私聊不会因此获得管理员经历。人物活动仍是虚拟状态，不能声称完成真实任务或线下行为。

## 性能、部署与验证

静态建筑和家具按几何类型进行实例化，颜色保留在实例属性中；发光部件单独合批，避免每件家具独立绘制。限制像素比为 1.5、动态上限约 30 帧，提供减少动态效果模式与离屏暂停。显示数量不影响记忆库容量。

部署需同时包含 `src/fish-headquarters.js`、`src/fish-hq-layout.js`、四个 `public/fish-hq*` 文件，以及相应桥接、协调器、静态路由、侧栏和原鱼窝入口变更。没有安装默认配置迁移，也不重置或替换用户的角色卡、聊天/记忆、媒体、家具或功能开关。

验证：`npm run test:fish-hq`、`npm run test:fish-hq-ui`。测试使用临时数据库与假平台连接，覆盖会话隔离、读操作无新增记忆/情感事件、真实任务优先、导航图门洞碰撞、鉴权、三维实际绘制、睡眠/醒来、全屏、移动端、原创房间模式不加载桌宠资源及无外部请求/模型/发消息。
