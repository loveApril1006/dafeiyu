# 目录说明

| 目录 | 用途 |
|---|---|
| `src/` | 机器人、鉴权、模型调用与功能服务 |
| `public/` | 后台界面，沿用同一主题 |
| `public/console/` | 后台样式及按职责拆分的交互脚本；由 `src/console-assets.js` 依原顺序拼接后一次提供给浏览器 |
| `companion/` | 本机生活服务和独立驱动；`*-data` 是私有运行数据 |
| `integrations/` | 固定版本的上游源码、许可证与按需运行环境 |
| `state/` | 私有状态、用量、审计与日志，不应公开打包 |
| `scripts/` | 自检、离线替身测试和维护脚本 |
| `dsh/agent-presets/` | 聊天预设与提示词 |
| `plugins/` | 本安装自己的工具守卫和配置插件 |

`config.json`、令牌、登录态、聊天记录与模型密钥属于本机私有配置。GPU运行库和模型体积较大，应与小型源码更新分开管理。`maintenance` 下的历史构建、测试安装和当前运行目录需要分别识别，不能按名字直接当作缓存删除。

修改后台交互时编辑对应的 `public/console/*.js`。分片共享原来的经典脚本作用域，保持清单中的执行顺序，不在分片中添加 `import`／`export`。静态契约测试通过 `readConsoleDocument()` 检查完整源代码；浏览器测试通过真实 HTTP 请求加载拆分后的资源。
