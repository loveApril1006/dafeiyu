# 当前设置作为打包基线

已生成 v22 完整安装包：`迁移包/大肥鱼完整版安装包-20261027-v22.zip`，约 8.73 GiB；同目录有 SHA-256 校验文件。旧安装包保留。

公开配置模板保存在 `packaging/default-settings.json`。本次读取时间和指纹在 `state/packaging-audit/defaults-export.json`，安装包内模板的字节校验与当前文件一致。

## 新安装采用的设置

- 当前使用二代仿真；活跃模式、逐条回复、工具开关、唤醒／等待／发送参数及上下文预算沿用当前值。
- 主动联系沿用当前「群聊、随机 10～60 分钟、到点必定安排」；固定间隔预设值也保留。实际发送仍须由安装者绑定自己的账号、群和允许名单。
- 语音、表情、黑话学习、角色注入上限、计价参数、聊天暂停状态等已识别的公开设置。
- 音乐、跑团、画图、表情包、QQ空间、B站、抖音的开关和额度／时间窗口。
- 当前人格正文与自称、角色状态的配置、作息和记忆投影参数；桌宠大小、行为、碎碎念、屏幕陪伴及内置音色选择。
- Mnemon、Context、Vision Router、ModSearch 和桌宠插件开关，以及已识别的公开插件参数。

导出采用字段白名单。配置中的未知字段默认不导出，后续新增设置需扩展 `src/portable-settings.js` 的对应 schema。

## 不会带入的内容

API密钥、控制台／服务令牌、密码、Cookie、登录态、源电脑模型账号和依赖账号的线路绑定；管理员QQ、群号、好友／群名单、B站UID和微信账号目录等绑定信息；聊天、长期记忆内容、角色关系记录、工作记录、草稿、已发内容、历史任务、用量计数、浏览器缓存和个人声音参考文件。

按具体好友／群绑定的初始提示词和会话配置不复制到新电脑。新安装根据安装者输入生成自己的账号、权限、路径和密钥；微信在完成新账号和名单配置前保持关闭。模型服务使用安装者自己填写的服务与凭据。

当前人格设置作为模板保留，但不复制角色的历史记忆或关系数据。源配置中已知的账号、密钥和本机路径若出现在可导出文字里，会被清除或替换。

## 覆盖更新的行为

v22 更新保留目标安装已有的功能开关、二代仿真参数、人格、账号、密钥和记录。公开模板仅用于新安装，不再像旧 v21 一样强制把已有配置改成写死的默认值。

模板由 `release-profile.mjs` 在首次安装配置完成后应用；现有安装迁移不会调用覆盖设置的分支。打包过程没有把这套模板重新套用到当前正在使用的安装。

## 验证结果

- 默认值应用和隐私陷阱测试：未知密钥字段、嵌套密钥、账号ID、聊天／记忆内容均被排除；新设备自己的账号、模型选择和本机路径保留。
- 真实 v22 配置加载器及更新迁移测试：新安装得到本次基线；覆盖更新的账号／密钥／历史文件逐字节保持，关闭的插件及个人音色设置保留。
- 安装引擎测试：差异更新、重复安装、取消、损坏文件、中断恢复和失败回退通过。测试均使用临时目录和模拟数据，没有启动平台服务。
- v22 安装器文字检查通过，窗口未显示、服务未启动。
- 完整包 88,794 个文件的 CRC 和 SHA-256 全部验证通过；扫描 88,708 个不超过 8 MiB 的文件，未发现采集到的 13 个本机凭据值；禁止携带的私有数据路径为 0。
- 另用 Windows .NET ZipArchive 读取新包，确认中文路径和配置模板可用。

构建复用了旧包中未变化的压缩记录，构建目录只保存 113 个变更／新增的程序文件及安装工具，没有再复制一份模型。完整包体积主要来自运行环境和模型。

## 后续维护

修改本机设置后，可用 `npm run export:packaging-defaults` 更新公开基线；用 `npm run test:packaging-defaults` 检查字段边界。发布新包时使用新的版本号和文件名，不覆盖已发布包。当前 v22 的构建与验证资料在 `maintenance/full-installer-v22`。

2026-10-27 的语音优化已加入当前源码和公开基线：默认空闲 5 分钟释放模型。已发布的 v22 ZIP 保持原样；后续发布必须使用新版本号。构建脚本现已同时收集语音轻量主服务和 3 个工作进程模块，排除 PyTorch C++ 开发头文件、静态库与 CMake 文件；保留推理 DLL、全部模型、4 个内置音色和第三方许可证。既有安装的开发文件通过可恢复的收纳工具处理，差异更新不会擅自删除目标电脑文件。详细验证和恢复方式见 [VOICE_OPTIMIZATION.md](VOICE_OPTIMIZATION.md)。

配置模板、包内默认配置和安装后的最终配置需一起验证；不要把正在使用的整个 `config.json` 或运行目录直接复制进安装包。
