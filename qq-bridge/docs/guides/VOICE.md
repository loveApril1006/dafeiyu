# 语音使用

本安装在机器人后台选择本机音色，并在QQ聊天设置中分别控制语音工具和AI语音能力。桌宠右键的音色选择与QQ共用本机语音服务的当前音色。读取音色失败时先检查语音服务是否运行，再刷新音色。

出厂示例中的AI发语音默认是关的。安装后的实际状态以后台当前开关为准；用户已经开启的音色、语音和工具设置不应被自检或优化重置。文字聊天与语音合成分别计开销，本机TTS主要占用内存、显存和推理时间。

后台提供图形界面用于音色选择和试听。源码版还可选配独立的 `voice-tool/`：`voice-gui.mjs` 是图形界面，`voice-cli.mjs` 是命令行入口，Windows启动器名为 `发语音-图形界面.cmd`。这些独立工具没有随本安装一起提供时，使用现有后台即可，不要把缺少可选工具当成QQ聊天故障。

语音文件发送、模型生成语音和手动试听是不同入口。开关关闭后不自动合成；手动试听只根据操作者的明确操作执行。合成失败时保留文字回复，不能把“已发送”的文本当作实际语音发送成功。
