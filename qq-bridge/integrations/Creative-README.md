# 娱乐与创作：独立接入说明

入口：机器人3100后台 → **娱乐与创作**。沿用机器人的配色。四项均为独立总开关，另有QQ与桌宠入口开关，初始全部关闭；不会向DSH注册这四个插件。

上游完整源码和许可证分别保存在 `music-player-upstream`、`diceframe-upstream`、`image-gen-upstream`、`meme-upstream`。版本及固定提交见 `creative-standalone/upstreams.json`。音乐复用原版完整React播放器，跑团复用原版纯逻辑引擎，画图复用原版提供方适配器与提示词目录，表情复用原版两套素材及说明。

## 使用

先打开对应总开关，再按需要打开“允许QQ命令”或“允许桌宠命令”。群聊和私聊继续受原机器人的会话授权规则控制，模型不能改开关。功能设置带revision，拒绝覆盖别处刚保存的修改。

| 功能 | QQ命令 | 桌宠输入 |
|---|---|---|
| 本地音乐、小说 | `#点歌 本地 名称`、`#听书 名称` | `点歌 名称`、`听书 名称` |
| 在线音乐 | `#点歌 QQ 名称`、`#点歌 网易 名称` | `点歌 QQ 名称` |
| 电台 | `#播放电台 台名` | `播放电台 台名` |
| 播放控制 | `#暂停音乐`、`#继续音乐`、`#停止音乐`、`#上一首`、`#下一首` | 去掉开头的 `#` |
| 跑团 | `#跑团 开场`、`#跑团 行动`、`#跑团 状态` | `跑团 开场`、`跑团 行动` |
| 骰子、检定 | `#掷骰 2d20kh1`、`#检定 侦察 d20 12` | 去掉开头的 `#` |
| 画图、改图 | `#画图 描述`；`#改图 描述`同时附上本条消息的参考图 | `画图 描述`；参考图编辑也可在后台完成 |
| 表情 | `#表情 开心` | `表情 开心` |

QQ点歌控制的是后台播放器或桌宠，播放位置在音乐设置中选择，不会自动向QQ上传整首歌曲。QQ生成图片和表情使用原有消息授权、发送队列与图片校验。明确命令只执行一次，发送结果不确定时不会自动重发。普通聊天不被当作操作命令。

桌宠创作命令直接调用机器人后台；日记、空间等原有生活命令继续走生活服务。桌宠音乐使用独立Audio，不替换聊天和碎碎念；聊天朗读时降低音乐音量，朗读结束后恢复。音乐指令通过既有状态长轮询传递，不增加一个空轮询。音乐媒体使用短期、只读、不可访问管理接口的随机播放链接；停止时撤销。

## 音乐、听书和新闻

打开完整播放器选择本地音乐和小说目录。在线账号在原版面板中本人登录，账号数据留在本机私有目录，不读取个人浏览器登录态。可用音质与播放权限仍由音乐服务及账号决定。

听书和新闻朗读改用本机17866 GPT-SoVITS，默认跟随机器人当前音色，也可在外层设置指定已有音色。无需另配原版MiMo语音密钥。新闻整理另有开关：一次最多5条、一次搜索和一次文本整理，资料有来源才保存。原版手动与定时入口调用同一条受限流程；关闭总开关后停止定时器和在途请求。仅新闻开关打开不代表已经设置定时任务。

为防止积压，听书最多2个合成等待项；语音缓存最多8段、合计32MB；书籍文本及结构最多缓存2本。单个直接读取文件最多8MB，EPUB展开内容累计最多16MB，超出需拆分章节。本地音乐使用Range流式读取，拖动进度不把整首音频反复读入内存。曲库最多500首、小说200本，最多遍历5000个目录并去重真实路径。

## 跑团、画图和表情

后台可编辑世界书、角色卡与场景笔记，导入导出JSON存档，并选择后台、桌宠、指定群或私聊的存档。各会话独立；有剧情生成进行时拒绝同时改档或掷骰，避免互相覆盖。模型使用现有无工具预设，不获得QQ、终端和文件工具。每轮只生成一次，历史最多8轮并受6000字符预算限制。

画图需要实际生图提供方及模型，普通聊天模型不能代替。支持OpenAI兼容、Gemini原生、通义原生、Seedream、xAI、GLM及本机ComfyUI；ComfyUI需导入API格式工作流。支持参考图编辑、草图画布、提示词灵感搜索和本机图库。每次只生成一张；图库最多100张、200MB；参考图按会话检查，不能从另一群的图库取图。模型密钥不回显，只发给明确配置的服务地址；图片下载不会带密钥，拒绝未授权的内网下载地址。

表情库初始含上游18张表情，可添加自己的图片，修改名称、含义、标签与分组。单张最多1MB、全库500张。原QQ收藏表情库保留，两套素材共用原来的安全图片发送出口。

## 费用和开关

三个可消耗任务默认每日尝试上限：音乐新闻／歌声转换4次、跑团剧情80次、图片生成10次。后台可改为0～1000。以北京时间按日记录，失败或取消也计入尝试次数，因为上游可能已开始处理。播放、掷骰、表情管理不占这些模型任务次数。

全局最多2个创作任务，同一功能同一会话同时只运行一个。QQ图片生成相隔至少60秒、剧情至少10秒。关闭功能或取消任务会中断本地等待与后续提交；外部服务已经开始的计算能否停止取决于该服务。

## 歌声：本机免训练转换

已部署独立、按次运行的 [Seed-VC](https://github.com/Plachtaa/seed-vc) V1 歌声转换引擎，源代码固定在 `51383efd921027683c89e5348211d93ff12ac2a8`，保留上游GPL-3.0许可证。上游已归档，后续升级需先验证兼容。模型约2.5GB，全部缓存在E盘的 `integrations/seed-vc-runtime/cache`；不修改GPT-SoVITS的模型和依赖。使用已有CUDA版PyTorch，独立venv仅补齐所需小依赖；只运行44.1kHz的F0歌声模型，不加载实时GUI、训练或V2模型。

后台“音乐与听书 → 歌声转换”选择本机免训练引擎，勾选允许歌声转换后保存音乐设置。角色音色复用上方指定的GPT-SoVITS参考录音，留空时跟随机器人当前音色；不会改变聊天音色。本人音色需上传3～30秒的WAV参考录音，建议10～25秒清晰、无伴奏的人声，最多6MB，仅保存本机。尚未收到本人的录音，因此本人音色当前待提供。复用参考录音不等于把GPT-SoVITS的权重当作RVC模型。

上传1～240秒、最多20MB的WAV人声轨，选择角色或本人后手动转换。默认25步，可选10～40步、升降调±12半音。全机最多一个转换进程，当前可用显存少于3.5GB时拒绝启动，不回退到长时间CPU计算。180秒超时、取消、关闭歌声开关或音乐总开关都会终止本次子进程。模型只在任务期间加载，子进程关闭后释放显存；临时输入和参考副本随任务清理，输出仅保留最近10份、单份最多24MB。转换不消耗聊天模型token，按音乐任务的每日上限计一次尝试。

已在RTX5060Ti8GB上离线完成真实转换：4秒上游示例人声 → 当前可莉参考音色，25步，输出44.1kHz单声道约3.99秒，首次约36秒。进程已退出，可用显存恢复约5.5GB；取消测试1.5秒后退出且临时目录为空。证据在 `state/creative-audit/seed-validation.json`。未自动播放或评价音色相似度，也没有用角色录音冒充本人的音色测试。输入需要已有的人声轨，当前不含原唱分离、模型训练或仅凭歌词作曲。

准备脚本 `scripts/prepare-seed-singing.py` 固定模型仓库revision及大权重SHA256，下载可恢复，推理强制离线。首次安装需先准备 `integrations/seed-vc-upstream` 和独立venv（复用本机GPT-SoVITS runtime，`--system-site-packages --without-pip`），仅在venv中安装 `munch==4.0.0`；运行准备脚本后，使用 `node scripts/check-seed-singing.mjs <1～10秒WAV人声轨>` 实际推理验证，验证成功才标记引擎可用。验证不会自动播放，结果保存在本机审计目录。安装清单、离线缓存和venv不放入普通源码包。

如已有RVC／So-VITS-SVC服务，也保留“已有服务”选项及两套模型ID。服务使用下列契约；协议不同需按其真实API适配：

```http
POST <本机服务地址>/convert
Content-Type: application/json

{"model":"所选小鸽子或本人模型ID","audio":"WAV人声轨的base64","format":"wav"}
```

服务应返回WAV二进制，输入输出与时限同上。外部服务取消后的计算能否停止取决于该服务。

## 数据、验证与更新

私有数据位于 `companion/creative-data`，目录ACL收紧。设置、密钥、音乐登录态、跑团存档、导入图片、歌声音频均不应放入发布包。关闭功能保留这些数据。上游升级先核对固定提交及适配断言，不要直接覆盖生成的host或把原版插件重新注册到DSH。

验证：`npm run test:creative`（实际骰子、存档隔离、取消、配额、原版音乐独立宿主、Range、图片适配、管理权限）；`npm run test:creative-ui`（需Playwright，真实浏览器测试开关、画布、图库、表情、跑团、取消、原版音乐界面与手机布局）。模型、QQ外发和图片提供方均使用替身，未把真实发送或收费生成作为部署测试。桌宠宿主类型检查和本轮音频／生活／音乐测试通过。
